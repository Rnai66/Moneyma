1. ข้อมูลที่เราเก็บรวบรวม

MoneyMa อาจเก็บข้อมูลต่อไปนี้ขึ้นอยู่กับการใช้งาน:

ข้อมูลบัญชี

  • ที่อยู่อีเมล
  • รหัสบัญชีผู้ใช้ (User ID)
  • ข้อมูลการยืนยันตัวตนสำหรับการเข้าสู่ระบบ

ข้อมูลการเงิน

  • รายรับและรายจ่ายที่ผู้ใช้บันทึกเอง
  • จำนวนเงิน, หมวดหมู่, งบประมาณ, วันที่
  • หมายเหตุหรือคำอธิบายที่ผู้ใช้กรอกเพิ่มเติม

การตั้งค่าแอป

  • ภาษา, ธีม และการตั้งค่าอื่นๆ ในแอป

ข้อมูล Crash และ Diagnostics

  • รายงานข้อผิดพลาด, เวอร์ชันแอป, ข้อมูลอุปกรณ์ (เพื่อแก้บั๊ก)

2. วัตถุประสงค์การใช้ข้อมูล

  • สร้างและจัดการบัญชีผู้ใช้
  • แสดงผลและจัดเก็บข้อมูลธุรกรรมทางการเงิน
  • สร้างรายงานสรุปและกราฟวิเคราะห์
  • สำรองและซิงค์ข้อมูลข้ามอุปกรณ์
  • ตรวจสอบและแก้ไขข้อผิดพลาดของแอป
  • ปรับปรุงและพัฒนาแอปอย่างต่อเนื่อง

3. การจัดเก็บข้อมูล

ข้อมูลอาจถูกจัดเก็บใน 2 รูปแบบ:

  • บนอุปกรณ์ — เก็บในหน่วยความจำของแอปบนโทรศัพท์/แท็บเล็ต
  • บน Cloud — เก็บบน Supabase เมื่อเปิดใช้งานฟีเจอร์ซิงค์หรือบัญชีผู้ใช้

4. การเปิดเผยข้อมูลแก่บุคคลที่สาม

เราไม่ขายข้อมูลส่วนตัวของคุณ

เราอาจแบ่งปันข้อมูลในกรณีต่อไปนี้เท่านั้น:

  • Supabase — ระบบฐานข้อมูลและการยืนยันตัวตน
  • Google Gemini AI — ประมวลผลรูปภาพสลิปและบิลชั่วคราว (ไม่เก็บรูปถาวร)
  • Firebase (Google) — รายงาน crash, analytics (ไม่มีข้อมูลการเงิน)
  • เมื่อกฎหมายกำหนดหรือมีคำสั่งศาล

5. การสแกนบิลและสลิปด้วย AI

เมื่อคุณใช้ฟีเจอร์สแกนสลิปหรือบิล:

  • รูปภาพจะถูกส่งไปยัง Google Gemini AI เพื่อประมวลผลชั่วคราวเท่านั้น
  • เราไม่เก็บรูปภาพของคุณไว้บนเซิร์ฟเวอร์ของเรา
  • ข้อมูลที่อ่านได้จากสลิปจะถูกนำเข้าแอปเพื่อให้คุณตรวจสอบก่อนบันทึก
  • กล้องใช้สำหรับฟีเจอร์นี้เท่านั้น ไม่มีการบันทึกวิดีโอหรือถ่ายภาพโดยไม่ได้รับอนุญาต

6. การสำรองข้อมูลบนคลาวด์

หากคุณเข้าสู่ระบบและเปิดใช้งาน Cloud Sync:

  • ข้อมูลธุรกรรมและการตั้งค่าจะถูกส่งไปเก็บบน Supabase
  • ข้อมูลสามารถซิงค์ข้ามอุปกรณ์ที่ใช้บัญชีเดียวกัน
  • คุณสามารถกู้คืนข้อมูลได้เมื่อติดตั้งแอปใหม่

7. ระบบบัญชีผู้ใช้

MoneyMa ใช้ Supabase Auth สำหรับการลงทะเบียน เข้าสู่ระบบ และจัดการ session ข้อมูลที่ใช้ได้แก่ อีเมล และ User ID สำหรับเชื่อมโยงข้อมูลการเงินกับบัญชีของคุณ

8. ระยะเวลาเก็บรักษาข้อมูล

  • ข้อมูลบัญชีเก็บไว้ตราบเท่าที่บัญชียังใช้งานอยู่
  • ข้อมูล Cloud จะถูกลบเมื่อคุณลบบัญชีหรือร้องขอการลบ
  • Crash logs เก็บไว้ชั่วคราวเพื่อการแก้บั๊กเท่านั้น

9. ความปลอดภัยของข้อมูล

  • ส่งข้อมูลผ่าน HTTPS / TLS เสมอ
  • ระบบยืนยันตัวตนและควบคุมการเข้าถึง
  • Supabase เป็น infrastructure ระดับ enterprise ที่มีมาตรฐานความปลอดภัยสูง

อย่างไรก็ตาม ไม่มีระบบใดที่ปลอดภัย 100% เราไม่สามารถรับประกันความปลอดภัยสมบูรณ์แบบได้

10. สิทธิ์และทางเลือกของผู้ใช้

  • แก้ไขหรือลบข้อมูลธุรกรรมในแอปได้ตลอดเวลา
  • ส่งออก (Export) ข้อมูลเป็น Excel
  • สำรองและกู้คืนข้อมูล
  • ออกจากระบบ (Sign out)
  • ขอลบบัญชีและข้อมูลทั้งหมด

1. Information We Collect

Account Information

  • Email address
  • User ID
  • Authentication credentials

Financial Information

  • Income and expense records entered by the user
  • Amounts, categories, budgets, dates, and optional notes

App Preferences

  • Language, theme, and other in-app settings

Crash & Diagnostics

  • Error reports, app version, device type (for debugging only)

2. How We Use Information

  • Create and manage user accounts
  • Store and display financial records
  • Generate reports and analytics
  • Support cloud backup and device synchronization
  • Detect and fix crashes and technical issues
  • Improve the app over time

3. How Information Is Stored

  • On-device — in local app storage
  • Cloud — on Supabase when sync or account features are enabled

4. Third-Party Sharing

We do not sell your data. We share only with:

  • Supabase — database and authentication
  • Google Gemini AI — temporary image processing for AI scan (images not retained)
  • Firebase (Google) — crash reporting and analytics (no financial data)
  • Law enforcement when legally required

5. AI Bill & Slip Scanning

  • Images are sent to Google Gemini AI for temporary processing only
  • We do not store your images on our servers
  • Extracted data is shown in-app for your review before saving
  • Camera is used solely for this feature — no background recording

6. Cloud Backup & Sync

  • Financial data is stored on Supabase when signed in with sync enabled
  • Data can be synced across devices sharing the same account
  • Data can be restored after reinstalling the app

7. Account System

MoneyMa uses Supabase Auth for sign-up, sign-in, and session management using your email and User ID.

8. Data Retention

  • Account data retained while your account is active
  • Cloud data deleted upon account deletion or written request
  • Crash logs retained temporarily for debugging

9. Data Security

  • HTTPS / TLS for all data in transit
  • Access controls and authentication safeguards
  • Supabase enterprise-grade infrastructure

No system is 100% secure. We cannot guarantee absolute security.
