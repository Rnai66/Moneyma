## 1. App icon — สร้างให้แล้ว

**ปัญหาของไฟล์เดิม** `public/assets/icons/icon-512.webp`:

- ตั้งชื่อเป็น `.webp` แต่เนื้อไฟล์จริงเป็น PNG (Play อาจปฏิเสธเพราะนามสกุลไม่ตรง)
- เป็น RGB ไม่มี alpha channel — Play ต้องการ **32-bit PNG with alpha**
- ตัวไอคอนวาดสี่เหลี่ยมมนซ้อนอยู่ข้างใน มีพื้นหลังเขียวเลอะที่มุมทั้งสี่
  Play จะครอบมุมมนของตัวเองทับอีกชั้น → กลายเป็น "กรอบในกรอบ" ดูไม่สะอาด

**ไฟล์ใหม่แก้ให้ครบแล้ว:** ครอปเอาเฉพาะตัวการ์ดด้านใน ขยายเต็มผืน 512×512 ล้างมุมให้เป็นสีเข้มทึบ และบันทึกเป็น PNG 32-bit พร้อม alpha

### จำนวนที่ควรทำ

| ระดับ | จำนวน | ได้อะไร |
|---|---|---|
| ขั้นต่ำที่ Play ยอมให้เผยแพร่ | 2 ภาพ | ผ่านแค่ให้ publish ได้ |

### วิธีถ่ายให้ได้ 1080×1920 พอดี

**ทางที่ตรงที่สุด — emulator หรือเครื่องจริง**

```bash
# ตั้ง emulator เป็น Pixel 6 (1080x2400) หรือใช้เครื่องจริงที่จอ 1080p
adb shell screencap -p /sdcard/s1.png
adb pull /sdcard/s1.png ~/projects/PFM/play-assets/screenshots/
```

ถ้าได้ 1080×2400 ให้ครอปเป็น 1080×1920 (อัตราส่วน 9:16) — สคริปต์ครอปอยู่ท้ายไฟล์นี้

**ทางที่เร็วกว่า — Chrome DevTools**

1. `npm start` แล้วเปิด `http://localhost:3000`
2. เปิด DevTools → Toggle device toolbar (`Cmd+Shift+M`)
3. ตั้ง Responsive เป็น **1080 × 1920** และ DPR = **1**
4. เมนู ⋮ ในแถบ device → **Capture screenshot**

### สคริปต์ครอป/ตรวจสอบภาพหลังถ่ายเสร็จ

วางภาพดิบไว้ใน `play-assets/screenshots/raw/` แล้วรัน:

```bash
cd ~/projects/PFM
python3 - << 'PY'
from PIL import Image
import glob, os
os.makedirs('play-assets/screenshots/final', exist_ok=True)
for i, f in enumerate(sorted(glob.glob('play-assets/screenshots/raw/*')), 1):
    im = Image.open(f).convert('RGB')          # ตัด alpha ออก -> 24-bit ตามสเปก
    w, h = im.size
    target_h = int(w * 16 / 9)
    if h > target_h:                            # ครอปจากกลางภาพให้ได้ 9:16
        top = (h - target_h) // 2
        im = im.crop((0, top, w, top + target_h))
    if im.width < 1080:
        im = im.resize((1080, int(1080 * im.height / im.width)), Image.LANCZOS)
    out = f'play-assets/screenshots/final/screenshot_{i:02d}.png'
    im.save(out, 'PNG', optimize=True)
    print(out, im.size, 'OK' if im.width >= 1080 else 'เล็กเกินไป')
PY
```
